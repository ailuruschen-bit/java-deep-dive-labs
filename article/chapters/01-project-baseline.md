# 第 1 章：项目基线与可复现环境

> 本章目前是占位正文。确定文章主题后，可保留本章作为环境说明，也可以替换为正式的第一章。

## 本章目标

建立最小、可重复运行的 Java 实验，并确认每章可以独立完成编译和测试。

## 环境基线

- JDK：8（由本章的 `.java-version` 声明）
- 构建工具：Maven Wrapper（版本固定在本章目录）
- 测试框架：JUnit Jupiter

## 运行实验

```bash
cd chapters/01-project-baseline
./mvnw test
```

预期结果：构建成功，并通过 `GreetingTest`。

## 实验说明

示例本身只返回一条固定消息。它的作用不是说明 Java 语法，而是验证章节的目录、依赖和测试可以在不读取其他章节的情况下独立工作。

## 小结

后续章节沿用相同编号关系，但可以独立调整 JDK、依赖及外部服务，不需要修改根目录构建配置。
